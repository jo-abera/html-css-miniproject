# 📊 DataSync Pro

A modern, responsive analytics dashboard and authentication UI built with **HTML5** and **Vanilla CSS3**.

## 🚀 Overview

**DataSync Pro** is a lightweight, dark-themed admin dashboard and authentication template. Built entirely with pure semantic HTML and modular CSS—no frameworks or build tools required.

### ✨ Key Features
- 🌑 **Modern Dark Theme**: Custom dark color palette using CSS variables.
- 📱 **Fully Responsive**: Adapts seamlessly to desktop, tablet, and mobile.
- 📊 **Analytics Dashboard**: KPI metric cards, team status, and activity overview.
- 🔐 **Auth Pages**: Clean Sign In & Sign Up templates with custom form inputs.
- ⚡ **Zero Dependencies**: Fast, lightweight, and framework-free.



## 📁 Project Structure

```text
html-css-miniproject/
├── index.html              # Main Dashboard
├── signin.html             # Sign In Page
├── signup.html             # Sign Up Page
└── assets/
    ├── style/
    │   ├── base.css        # Design tokens, reset & base styles
    │   ├── style.css       # Dashboard layout & media queries
    │   ├── signinstyle.css # Sign In page styles
    │   └── signupstyle.css # Sign Up page styles
    └── images/             # Avatars and UI graphics
```

## ⚡ Quick Start

No installation needed. Simply open the files in your browser:

1. Clone or download the repo:
   ```bash
   git clone https://github.com/jo-abera/html-css-miniproject.git
   ```
2. Open `index.html` in your browser (or use VS Code **Live Server**).
